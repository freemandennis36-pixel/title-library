# KTK Title Library

Free titles for **[KTK Live Studio](https://github.com/freemandennis36-pixel/ktklivestudio)** — the free church-first live streaming studio for Windows.

## How to use

1. Download a file from this page (click it, then **Download raw file** ⬇).
2. In KTK Live Studio: **Add Input → Title / XAML → ⬆ Import titles…** — or just drop the file on the studio.
3. Your titles appear under **My titles**. Double-click one to add it, then type your own words in its settings.

## What is here

| Folder | What it is |
|---|---|
| [`packs/`](packs) | **Title packs** (`.ktkpack`) — several titles in one file. Import once, get them all. |
| [`titles/`](titles) | Single titles (`.ktktitle`). |
| [`animated/`](animated) | Animated accents with a **see-through background** (`.webm`, VP9 with alpha). Put one on an overlay (1–4) under a lower third. |

### Packs
- **Sunday Service Essentials** — welcome, pastor lower third, sermon title, giving details, prayer line, scripture.
- **Celebrations** — birthday, wedding, thanksgiving, baby dedication.
- **Youth Night** — glass lower third, hashtag bug, neon countdown, big title.

Every title uses fonts that come free inside KTK Live Studio (59 free fonts), so they look the same on every computer.

## Make your own
In KTK Live Studio open any title's settings → **★ Save as my title** or **⬇ Export…**.
A `.ktktitle` file carries its pictures inside it, so you can share it on WhatsApp or email.

Want to add yours to this library? Open a pull request with your `.ktktitle` / `.ktkpack` file.

## Other free sources
- **vMix GT titles** (`.gtzip` / `.xaml`) — KTK imports them *best effort*: the background picture and up to 4 texts. Animations, effects and drawn shapes are not converted.
- **PNG with transparency** — import it and KTK turns it into a "Picture + text" title.
- **Animated titles with alpha** — `.webm` (VP9 alpha) plays directly; `.mov` (ProRes 4444 / QuickTime Animation) is converted for you.
- **Free fonts** — [Google Fonts](https://fonts.google.com/): download, then **＋ Import font…** in a title's settings.
